# Política de Privacidade do Andy Hub

Última atualização: novembro de 2026.

## O que é o Andy Hub

Andy Hub é uma ferramenta pessoal de organização de conteúdo, contatos e e-mails. Ela é usada somente pelo próprio autor, no computador dele. Não é oferecida ao público e não possui outros usuários.

## Quais dados são acessados

Quando o autor conecta uma conta Gmail, o aplicativo lê, organiza e envia mensagens dessa conta, a pedido do próprio autor, para exibi-las e organizá-las dentro do aplicativo.

## Onde os dados ficam

Todos os dados ficam armazenados apenas no computador do autor. Eles não são enviados para servidores do desenvolvedor, não são vendidos, não são compartilhados com terceiros, não são usados para publicidade e não são usados para treinar modelos de inteligência artificial.

## Uso limitado dos dados do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

## Como remover o acesso

O autor pode desconectar a conta a qualquer momento dentro do aplicativo e revogar o acesso em myaccount.google.com/permissions. Ao desconectar, as mensagens guardadas daquela conta são removidas do aplicativo.

## Contato

Dúvidas podem ser enviadas ao e-mail de suporte exibido na tela de autorização do Google.
